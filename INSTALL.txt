========================================
CAFFÈ DELL'ANGOLO - IL GIOCO v2.1
INSTALLAZIONE SU IONOS
========================================

✅ FUNZIONALITÀ:
- Controlli solo swipe (touch)
- Classifica GLOBALE condivisa tra partecipanti
- Pannello ADMIN per personalizzare evento, colori, immagini
- Supporto immagini personalizzate per personaggi
- Database MySQL opzionale (con fallback file JSON)

========================================
REQUISITI
========================================

- Hosting IONOS con PHP 7.4+
- MySQL (opzionale, per immagini personalizzate)
- Dominio/sottodominio configurato

========================================
INSTALLAZIONE BASE (SENZA DATABASE)
========================================

1) Apri IONOS > Hosting > Gestisci > File Manager
2) Entra nella root pubblica (`/` o `htdocs`)
3) Carica TUTTI i file/cartelle sopra
4) Imposta permessi:
   - cartella `data/`: 755
   - file `data/leaderboard.json`: 664
   - cartella `upload/`: 755
5) Apri: https://tuodominio.it/
6) Admin: https://tuodominio.it/admin.html

Senza database, le configurazioni usano localStorage
e le immagini NON vengono salvate sul server.

========================================
INSTALLAZIONE CON DATABASE MYSQL
========================================

1) Crea database MySQL da IONOS:
   IONOS > Database > Crea database MySQL
   Annota: host, nome_db, utente, password

2) Importa db.sql:
   IONOS > Database > phpMyAdmin > Importa > db.sql

3) Modifica api/db_config.php con le tue credenziali:
   
   define('DB_HOST', 'db12345.hosting.ionos.it');
   define('DB_NAME', 'dbs12345');
   define('DB_USER', 'dbu12345');
   define('DB_PASS', 'la_tua_password');
   
   define('ADMIN_PASSWORD', 'cambia_questa_password');

4) Carica tutti i file su IONOS

5) Verifica che upload/ abbia permessi 755

========================================
PANNELLO ADMIN
========================================

URL: https://tuodominio.it/admin.html
Password default: admin123 (CAMBIALA in db_config.php!)

Funzioni:
- Modifica titolo, data, location evento
- Cambia colori tema
- Cambia emoji/immagini personaggi
- Visualizza e svuota classifica

========================================
TEST RAPIDO
========================================

1) Apri https://tuodominio.it/api/config.php
   Deve mostrare JSON con "success": true

2) Apri https://tuodominio.it/api/leaderboard.php
   Deve mostrare JSON con "success": true

3) Gioca e salva punteggio, verifica in classifica

4) Apri admin.html e modifica configurazione

========================================
TROUBLESHOOTING
========================================

Errore "Database non configurato":
→ Le credenziali in db_config.php sono errate
→ Il database non esiste o non è accessibile
→ Il gioco funziona comunque con fallback locale

Errore upload immagini:
→ Verifica permessi cartella upload/ (755)
→ Verifica che .htaccess sia presente in upload/

Classifica non condivisa:
→ Verifica che data/leaderboard.json sia scrivibile (664)
→ Controlla errori PHP nel log IONOS

========================================
SICUREZZA
========================================

⚠️ IMPORTANTE: Modifica sempre ADMIN_PASSWORD
   in api/db_config.php prima di andare online!

I file .htaccess proteggono:
- data/ → blocca accesso diretto ai JSON
- upload/ → consente solo immagini, blocca PHP
